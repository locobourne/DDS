🛣️Rutas y Navegación

Ruteo del Lado del Cliente

URL Cambia

/home → /productos

Sin Request

No hay llamada al servidor

Renderizado

Componente se actualiza inmediatamente

Los ruteos del lado del cliente permiten que la aplicación actualice la URL sin necesidad de hacer un request al servidor, renderizando inmediatamente el componente de la interfaz.

⚡Ventajas del Client-Side Routing

Experiencias Más Rápidas

El navegador no necesita solicitar un documento completamente nuevo o volver a evaluar los activos CSS/JS.

Experiencias Más Dinámicas

Es posible aplicar animaciones y transiciones suaves entre páginas.

Comparación de Rendimiento

Ruteo Tradicional
Request → Response → Render
~2-5 segundos
VS
Client-Side Routing
URL Change → Render
~100-300ms

⚙️Configuración de React Router

Instalación

npm install react-router-dom

Configuración Básica

import { BrowserRouter, Routes, Route } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/productos" element={<Productos />} />
        <Route path="/contacto" element={<Contacto />} />
      </Routes>
    </BrowserRouter>
  );
}

🔍Cómo Funcionan las Rutas

Proceso de Matching

React Router recorre cada ruta en orden:

  1. Compara la URL actual con la propiedad "path" de cada ruta
  2. La primera ruta que coincida se renderizará
  3. Las demás rutas no se renderizarán
Routes Container
Route: path="/"
Route: path="/productos"
Route: path="/contacto"

Ejemplo de Matching

URL actual: /productos

✅ Se renderiza el componente <Productos />

🌳Rutas Anidadas

Routes utiliza una sintaxis de árbol de rutas anidadas, permitiendo definir rutas complejas de manera flexible. 

    <Routes>
      <Route path="/" element={<Layout />}>
        <Route index element={<Home />} />
        <Route path="productos" element={<ProductosLayout />}>
          <Route index element={<ProductosList />} />
          <Route path=":id" element={<ProductoDetalle />} />
          <Route path="categoria/:categoria" element={<Categoria />} />
        </Route>
        <Route path="contacto" element={<Contacto />} />
      </Route>
    </Routes>

🎣Hook useParams

Extrayendo Parámetros de la URL

Ruta: /productos/categoria/electronicos/123
Patrón: /productos/categoria/:categoria/:id
import { useParams } from 'react-router-dom';

function ProductoDetalle() {
  const { categoria, id } = useParams();
  
  return (
    <div>
      <h2>Producto ID: {id}</h2>
      <p>Categoría: {categoria}</p>
    </div>
  );
}

// Resultado:
// Producto ID: 123
// Categoría: electronicos

💡 Casos de Uso Comunes

  • IDs de productos: /producto/:id
  • Categorías: /categoria/:categoria
  • Usuarios: /usuario/:username
  • Múltiples parámetros: /tienda/:tienda/producto/:id

🧭Hook useNavigate

Permite navegar programáticamente entre rutas sin usar enlaces. 

import { useNavigate } from 'react-router-dom';

function LoginForm() {
  const navigate = useNavigate();
  
  const handleLogin = async (userData) => {
    try {
      await login(userData);
      // Navegar al dashboard después del login exitoso
      navigate('/dashboard');
    } catch (error) {
      console.error('Error en login');
    }
  };
  
  const goBack = () => {
    navigate(-1); // Volver atrás
  };
  
  return (
    <form onSubmit={handleLogin}>
      {/* ... campos del formulario ... */}
      <button type="submit">Iniciar Sesión</button>
      <button type="button" onClick={goBack}>Volver</button>
    </form>
  );
}

Navegación Condicional

Redirigir basado en el resultado de operaciones (login, validaciones, etc.)

Navegación Programática

🔗Componente NavLink

NavLink es como Link pero proporciona estilos especiales cuando la ruta está activa. 

import { NavLink } from 'react-router-dom';

function Navigation() {
  return (
    <nav>
      <NavLink 
        to="/" 
        className={({ isActive }) => 
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        Inicio
      </NavLink>
      
      <NavLink 
        to="/productos"
        style={({ isActive }) => ({
          color: isActive ? '#fff' : '#333',
          backgroundColor: isActive ? '#007bff' : 'transparent'
        })}
      >
        Productos
      </NavLink>
    </nav>
  );
}

✨ Características Principales

  • isActive: Indica si la ruta actual coincide
  • isPending: Indica si la navegación está pendiente
  • Estilos dinámicos: className y style pueden ser funciones
  • end prop: Coincidencia exacta de rutas

🏗️Ejemplo Completo

import { BrowserRouter, Routes, Route, NavLink, useParams, useNavigate } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <Navigation />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/productos" element={<ProductosLayout />}>
          <Route index element={<ProductosList />} />
          <Route path=":id" element={<ProductoDetalle />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}

function Navigation() {
  return (
    <nav>
      <NavLink to="/" end>Inicio</NavLink>
      <NavLink to="/productos">Productos</NavLink>
    </nav>
  );
}

function ProductoDetalle() {
  const { id } = useParams();
  const navigate = useNavigate();
  
  return (
    <div>
      <h1>Producto {id}</h1>
      <button onClick={() => navigate('/productos')}>
        Volver a Productos
      </button>
    </div>
  );
}
