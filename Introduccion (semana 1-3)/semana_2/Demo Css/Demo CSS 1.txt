Paso 1
======
Crear un documento HTML básico que tenga como título del documento "Hola Mundo", un encabezado y un párrafo.

<!DOCTYPE html>
<html>
<head>
  <title>Hola Mundo</title>
</head>
<body>
  <h1>Hola Mundo</h1>
  <p>Mi primer documento html</p>
</body>
</html>
